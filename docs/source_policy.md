# Sources and evidence boundaries

Each knowledge record or WP2 item carries its original technical-source reference and a source locator. Public distribution cleanup removes obsolete local PDF-mirror SHA-256 values, internal inspection-process labels and bibliography-assembly prefaces without inventing technical source support. Preserved source IDs, physical/printed page references, chapters, equations, figures and relevant technical comments are the available claim-level locators. Some source locators are broader than page/section precision; readers must check the cited primary material for any intended use.

`SRC-NNN` identifiers are historical, module-local labels and **not globally unique**. `metadata/source_register.csv` assigns deterministic `ref-<12 hex>` keys to each distinct *complete citation string* (not one key per deduplicated publication). `metadata/source_item_index.csv` maps each WP1/WP2 record to that key and separately shows the legacy reference/locator IDs. Neither an ID match nor a source-key mapping is evidence of technical support.

Source-reference/locator named-work consistency was checked against the cited Pierret and Taur–Ning editions at item level. Some legacy-ID differences name the same Taur–Ning work under different module-local aliases; these are displayed in the source-item index and are not bibliographic conflicts. Bibliographic fields retain the cited works and URLs without generator-stage assembly labels.

The register and crosswalk are discovery tools, not evidence that each claim was independently re-verified during this public packaging step. Some locators remain broader than page/section precision.

Third-party textbooks, articles and other reference documents are **not bundled or relicensed**. Users are responsible for obtaining sources lawfully and respecting underlying rights.
