# Limitations

- The collection-level release metadata records 225 approved WP1 records and 769 approved WP2 items. Package validation is not a substitute for expert interpretation of every possible response.
- Source references and locators preserve the cited technical works, with reference-locator named-work consistency checked against the cited Pierret and Taur–Ning editions. The source register generates unique keys for **citation strings**, not necessarily deduplicated works. Legacy `SRC-###` identifiers are module-local and can differ for the same publication.
- Public answers and rubrics permit benchmark contamination. Use a separate nonpublic test set for blind performance claims.
- The spreadsheet is a convenience projection and omits extended scoring policies present in JSON.
- Runtime prompt isolation, retrieval leakage control, evaluator calibration, and run-completeness auditing remain downstream evaluation responsibilities.
- Covered original content is offered under the component-specific licenses identified in `LICENSING.md`; no rights in external third-party sources are granted by this release. The rights holder approval evidence is held outside the public package.
