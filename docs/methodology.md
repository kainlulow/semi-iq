# Review and curation methodology

WP1 defines reusable semiconductor knowledge units with technical-source citations. WP2 defines assessment items mapped to approved WP1 records. Review considers technical accuracy, source support, question quality, answer completeness, scoring consistency, difficulty, and duplication. Final approval belongs to human reviewers.

The release records 225 approved WP1 records and 769 approved WP2 items; the WP2 collection completed review under Project B V1.3. This packaging pass checked structure, IDs, WP1 linkage, criterion point totals, privacy, workbook alignment, and checksums. It did not modify question, answer, rubric, criterion points, answer alternatives or locator technical content; this public-format pass removed local file hashes and redundant review-process wording from source metadata. Original private approved masters remain unchanged.

Revise approved technical content only through a new versioned review cycle.
